# golden-farewell

A private, client-side encrypted farewell keepsake for Sheikh Mehvish Qadir with a Golden Memory Frame and Dua.

## Features
- **Client-Side AES-256-GCM Encryption**: All personal messages and portrait artwork are encrypted.
- **Passcode Gate**: Enter passcode to decrypt and unlock the keepsake in-memory.
- **Golden Memory Frame**: Interactive and exportable keepsake frame (PNG and PDF downloads).
- **Tech Stack**: Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion, Web Crypto API.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
